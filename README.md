# Detailed Connectomic Cluster Repository

Welcome to the Connectomic cluster repository, a resource for the "Detailed Connectomic Cluster" project. This repository contains scripts and resources related to the project.

## Article Reference

- Title: Detailed Connectomic Cluster Resource for White Matter Mapping From Ultra-High-Field Diffusion MRI
- Authors: Hiuying Yip, Yifei He, Yu Xie, Fan Zhang, Ye Wu
- Year: 2025

## Software dependencies:

The connectomic cluster generation pipeline makes use of the following software packages:

- FreeSurfer: version 7.1.1
- FSL: version 6.0.3
- MRtrix3
- ANTs
- https://github.com/pnlbwh/pnlNipype
- Matlab 2024B

The following Python packages were additionally utilized:

- NumPy
- NiBabel
- Dipy
- Scikit-learn
